| 1 | Linear Regression | auto | 24 | Least squares (residuals, rotate the line, minimise SSR). R² = (Var(mean) − Var(fit)) / Var(mean); example 11.1 vs 4.4 → 0.6 = 60%. Extra parameters never make SS(fit) worse, so report adjusted R². Two points always give R² = 100%, so a p-value is needed. F = explained / unexplained variance, with degrees of freedom (p_fit − p_mean), (n − p_fit). p-value comes from a histogram of F over random data, approximated by the F-distribution. Takeaway: R² should be large and the p-value small. |
| 2 | Logistic Regression | manual | 8 | Linear regression review (R², p-value, prediction = machine learning). Logistic regression predicts true/false using an S-shaped logistic curve from 0 to 1 (a probability), used for classification at a 50% threshold. Works with continuous and discrete variables. Wald's test checks whether a variable is useful ("astrological sign is totes useless"). There are no residuals, so no least squares and no R²; it is fit with maximum likelihood. |
| 3 | Bias and Variance | manual | 6 | Mouse weight vs height with a curved true relationship. Train/test split. Straight line = high bias, low variance. Squiggly line = low bias, high variance, overfit (SSR of zero on training data but bad on test data). Bias = inability to capture the true relationship; variance = difference in fits between datasets. Sweet spot via regularization, boosting, bagging. |
| 4 | Cross Validation | manual | 5 | Choose between methods (logistic regression, KNN, SVM) for heart disease. Training = estimating parameters; testing = evaluating. Don't reuse training data for testing. Blocks: 4-fold, leave-one-out, 10-fold (common). Can tune parameters, e.g. ridge's lambda. |
| 5 | Ridge (L2) Regression | auto | 19 | Two-point training data means least squares overfits (high variance). Ridge minimises SSR + λ·slope². Worked example: 1.69 vs 0.74. Adds a little bias for a big drop in variance. Smaller slope means less sensitivity to weight. λ ranges from 0 to ∞ (λ = 0 is least squares; large λ pushes the slope asymptotically to 0); λ is picked by 10-fold CV. Works for discrete variables (diet difference) and for logistic regression (sum of likelihoods). Penalty covers all parameters except the y-intercept. Can solve 10,001 parameters with about 500 samples. |
| 6 | Lasso (L1) Regression | auto | 8 | Lasso = SSR + λ·\|slope\|. Similar to ridge: same contexts, the penalty excludes the intercept, and it can shrink parameters unequally. Key difference: lasso can shrink a parameter all the way to 0 (ridge only gets asymptotically close), so lasso removes useless variables. Lasso is better with many useless variables; ridge is better when most are useful. |
| 7 | Decision and Classification Trees | manual | 16 | Classification tree vs regression tree. Root, internal nodes (branches), leaves. True goes left. Building a tree from Loves Popcorn / Loves Soda / Age → Cool As Ice. Impure leaves. Gini impurity = 1 − p(yes)² − p(no)²; weighted average across leaves (0.405 popcorn, 0.214 soda). Numeric features: sort, take adjacent averages as thresholds (age 15/44 tie at 0.343). Soda at the root, then age < 12.5. Leaf output = majority class. Overfitting is handled by pruning or a minimum number of people per leaf, chosen by CV. |
| 8 | Random Forests Part 1 | manual | 9 | Trees are inaccurate on new data. Step 1: a bootstrapped dataset (same size, sampling with replacement). Step 2: build a tree using a random subset of variables at each step. Repeat hundreds of times. Predict by majority vote. Bagging = bootstrapping + aggregating. About one third of the data is out-of-bag; out-of-bag error = proportion of OOB samples misclassified. Tune the number of variables per step using OOB error. |
| 9 | AdaBoost | auto | 18 | Three ideas: (1) weak learners, almost always stumps; (2) stumps get different amounts of say; (3) each stump accounts for the previous stump's mistakes. Initial sample weight = 1/N. Pick the stump by Gini index. Total error = sum of the weights of misclassified samples. Amount of say = ½·ln((1 − TE)/TE) (TE 1/8 → 0.97; 3/8 → 0.42). Misclassified weight × e^{say}, correct weight × e^{−say}, then normalise. Next stump via a weighted Gini, or by resampling into a new dataset. Classify by summing amounts of say per class. |
| 10 | Gradient Boost Part 1 | auto | 14 | Gradient boost for regression (not the same as linear regression). Compared with AdaBoost: starts with a single leaf equal to the mean (71.2 kg); trees are larger than stumps (8–32 leaves in practice, 4 in the example); all trees are scaled by the same learning rate. Pseudo residuals = observed − predicted. Learning rate 0.1: 71.2 + 0.1·16.8 = 72.9; then 74.4. Many small steps give lower variance (Jerome Friedman). Stop at the maximum number of trees or when there is no improvement. |
| 11 | XGBoost Part 1 | auto | 20 | Initial prediction 0.5 by default. XGBoost trees fit residuals. Similarity = (Σ residuals)² / (n + λ). Gain = left + right − root (dosage < 15 → 120.33). Default maximum depth is 6. Pruning: if gain − γ < 0, prune (γ = 130 keeps the tree, 150 removes it). λ shrinks similarity scores (more for small leaves), giving more pruning; γ = 0 doesn't turn pruning off. Leaf output = Σ residuals / (n + λ). Learning rate eta defaults to 0.3: 0.5 + 0.3·(−10.5) = −2.65. |
| 12 | SVM Part 1 | auto | 17 | Threshold, margin, maximal margin classifier (sensitive to outliers). Soft margin allows misclassifications (bias/variance trade-off), chosen by CV. Support vector classifier; support vectors are the points on the edge of and inside the soft margin. Point / line / plane / hyperplane (flat affine subspaces). The SVM moves data to a higher dimension (dosage²). Kernels: polynomial (degree d, chosen by CV) and radial (RBF: infinite dimensions, behaves like weighted nearest neighbours). Kernel trick: compute the high-dimensional relationships without transforming the data. |
